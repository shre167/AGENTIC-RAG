# MIGRATION GUIDE: Chroma to PostgreSQL with pgvector

## QUICK START (5 Steps)

### Step 1: Install PostgreSQL
- Download from: https://www.postgresql.org/download/windows/
- Run installer, remember password
- Default port: 5432

### Step 2: Create Database
Open Command Prompt and run:
`
psql -U postgres -c "CREATE DATABASE rag_helpdesk;"
psql -U postgres -d rag_helpdesk -c "CREATE EXTENSION IF NOT EXISTS vector;"
`

### Step 3: Install Python Dependencies
`
pip install psycopg2-binary sqlalchemy sqlalchemy-utils pgvector
`

### Step 4: Update .env File
`
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/rag_helpdesk
`

### Step 5: Replace Vector Store Class
In src/rag_pipeline/pipeline.py, change:
FROM:  from src.vector_store import ChromaVectorStore
TO:    from src.postgres_vector_store import PostgresVectorStore

Then change:
FROM:  self.vector_store = ChromaVectorStore(...)
TO:    self.vector_store = PostgresVectorStore()

---

## KEY DIFFERENCES

CHROMA:
- Stores in: ./vectorstore/chroma.sqlite3
- Local file-based
- SQLite backend
- Single user

POSTGRESQL:
- Stores in: PostgreSQL database
- Network-based (can be remote)
- ACID compliant
- Multi-user support
- Better scaling (100M+ vectors)

## MIGRATION EXISTING DATA

To migrate chunks from Chroma to PostgreSQL:

`python
from src.vector_store import ChromaVectorStore
from src.postgres_vector_store import PostgresVectorStore
from src.config import VECTORSTORE_DIR

chroma = ChromaVectorStore(persist_directory=VECTORSTORE_DIR)
postgres = PostgresVectorStore()

# Get all chunks from Chroma
data = chroma.collection.get(include=["documents", "metadatas", "embeddings"])

# Insert into PostgreSQL
postgres.add_documents(
    texts=data["documents"],
    embeddings=data["embeddings"],
    metadatas=data["metadatas"],
    ids=data["ids"],
)

print(f"Migrated {len(data['ids'])} chunks")
`

## TROUBLESHOOTING

ERROR: psql not found
FIX: Add PostgreSQL bin to PATH:
  Set PATH to include: C:\Program Files\PostgreSQL\15\bin\

ERROR: extension vector not found
FIX: Install pgvector extension:
  psql -U postgres -d rag_helpdesk -c "CREATE EXTENSION vector;"

ERROR: connection refused
FIX: Check PostgreSQL is running:
  Services > PostgreSQL

ERROR: permission denied
FIX: Grant privileges:
  psql -U postgres -d rag_helpdesk -c "GRANT ALL ON SCHEMA public TO PUBLIC;"

## PERFORMANCE

Once running, add indexes for speed:

`sql
psql -U postgres -d rag_helpdesk

CREATE INDEX idx_book_title ON chunks(book_title);
CREATE INDEX idx_chapter ON chunks(chapter_num);
CREATE INDEX idx_embedding ON chunks USING ivfflat (embedding vector_cosine_ops);

ANALYZE chunks;
`
